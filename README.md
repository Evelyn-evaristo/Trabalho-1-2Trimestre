# Trabalho 1 — Programação Web 1

Este repositório contém o **Trabalho 1 do 2º Trimestre da disciplina de Programação Web 1**.

O projeto é composto por **8 atividades práticas**, desenvolvidas principalmente com **HTML e JavaScript**, com foco no desenvolvimento da lógica de programação e na resolução de diferentes problemas utilizando conceitos estudados durante as aulas.

## Tecnologias utilizadas

* HTML5
* JavaScript
* CSS, quando necessário

## Conteúdo das atividades

### Atividade 1 — Estacionamento

Programa responsável por calcular o valor de permanência de um veículo em um estacionamento, considerando diferentes valores por hora e aplicação de desconto em determinadas situações.

### Atividade 2 — Caixa eletrônico

Simulação de um caixa eletrônico com opções para consultar saldo, realizar depósitos e saques, além de controlar a quantidade de operações realizadas.

### Atividade 3 — Números da sorte

Programa que analisa números e verifica se eles atendem às condições necessárias para serem classificados como **números da sorte**.

### Atividade 4 — Anagramas quase perfeitos

Programa que recebe duas palavras ou textos e verifica se eles podem ser considerados **anagramas quase perfeitos**, comparando caracteres, frequência e posicionamento.

### Atividade 5 — Fatorial primo

Programa que calcula o fatorial de números informados pelo usuário e verifica determinadas condições relacionadas a números primos.

### Atividade 6 — Média de alunos

Sistema que recebe nomes e notas de alunos, calcula a média ponderada e apresenta a classificação de cada estudante.

### Atividade 7 — Jogo de adivinhação

Jogo em que o usuário deve descobrir um número aleatório entre **1 e 100**, recebendo dicas durante as tentativas.

### Atividade 8 — Calculadora de expressões

Programa capaz de interpretar uma expressão matemática escrita pelo usuário e realizar operações de:

* Adição;
* Subtração;
* Multiplicação;
* Divisão.

O cálculo respeita a ordem de precedência das operações matemáticas sem utilizar `eval()`.

## Conceitos trabalhados

Durante o desenvolvimento das atividades foram utilizados conceitos como:

* Variáveis;
* Funções;
* Estruturas condicionais;
* Laços de repetição;
* Arrays;
* Objetos;
* Manipulação de strings;
* Operadores matemáticos e lógicos;
* Validação de dados;
* Manipulação do DOM;
* Entrada e saída de dados;
* Lógica de programação.
