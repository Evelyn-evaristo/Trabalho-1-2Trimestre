# Trabalho-1-2Trimestre
Trabalho do 2º trimestre de Programação Web 1, composto por 8 atividades práticas desenvolvidas com HTML e JavaScript. Os exercícios abordam lógica de programação, funções, condicionais, laços de repetição, arrays, strings, cálculos matemáticos, validação de dados e manipulação do DOM, aplicados na resolução de diferentes problemas..
